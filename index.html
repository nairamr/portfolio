Making Integration Knowledge Accessible with AI

Led the end-to-end definition and rollout of an internal AI-powered knowledge platform for Sales, Implementation, and Customer Success. By unifying transportation API specifications, carrier EDI documentation, and onboarding guides into a conversational search experience, we reduced technical escalations to engineering and accelerated customer onboarding.

See my other work

The Problem

Customer onboarding involved four separate teams, but integration capabilities, technical constraints, and onboarding steps were fragmented across scattered documents and subject-matter experts. Even routine integration questions required engineering bandwidth, creating friction in sales conversations and delaying customer go-lives.

The Solution

We launched a centralized AI knowledge assistant that gave customer-facing teams instant, verified answers on platform capabilities, API specifications, and carrier EDI requirements. The platform also supported live API demonstrations through Postman, reducing technical dependency during pre-sales.

My Approach

  • Rapid AI prototyping: Built interactive concepts and working demonstrations before engineering kickoff so stakeholders could visualize integration workflows, team handoffs, and the customer journey.
  • Requirement refinement: Used early concept testing with end users to identify documentation gaps, edge cases, and workflow bottlenecks before development resources were committed.
  • Trust & validation: Partnered with engineering to establish retrieval-augmented grounding and run end-to-end testing, validating response accuracy, source attribution, and API endpoints before full deployment.

Impact & Results

82% zero-edit acceptance rate on AI-generated API integration summaries across Sales and Customer Success.

2 weeks saved on average customer onboarding duration.

60% internal adoption across Sales and Implementation within the first month.

30%+ reduction in routine technical inquiry escalations to senior engineering.
